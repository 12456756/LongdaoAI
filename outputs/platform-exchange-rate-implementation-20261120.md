# 平台统一汇率实施记录

日期：2026-11-20。

## 管理入口

系统设置 → 支付设置 → 平台统一汇率。即使未启用在线支付也可编辑。

唯一配置键为 `platform_usd_to_cny_rate`，含义为 `1 USD = R CNY`，默认 `7.15`。以十进制字符串保存，允许最多 6 位整数、12 位小数，必须大于零。空值、负数、零、科学计数法及超出精度的值会返回明确错误。

写入仅通过系统设置接口；支付配置接口和收银台只读同一个值。旧充值倍率、旧订阅汇率及旧人民币展示汇率已移除，迁移 184 删除旧配置，不再推导倒数或互相覆盖。未做历史价格换算或旧字段兼容。

## 计算规则

| 场景 | 规则 |
|---|---|
| 人民币充值 | 人民币本金 ÷ R，美元到账保留 8 位小数 |
| 美元充值 | 本金直接作为美元到账金额 |
| 订阅套餐 | 价格及原价统一为 USD，管理页面不再提供任意币种输入 |
| 订阅收人民币 | 套餐美元价格 × R，四舍五入到人民币分，再单独添加支付手续费 |
| 订阅收美元 | 按套餐美元价格收款，再添加支付手续费 |
| 人民币展示 | 美元余额或费用 × 同一个 R |
| 其他支付币种 | 后端拒绝充值和订阅，收银台隐藏对应方式 |
| 退款 | 使用原订单到账额与实付额的比例，按原支付币种取整，不读取当前汇率 |

充值手续费不计入美元到账余额。订单保存本次汇率快照、到账金额和实际支付金额。修改汇率不会重算已创建订单；历史用量页面的人民币参考展示使用当前汇率。

模型基础价格、用户余额和模型扣费仍以 USD 为本位；分组倍率及账号报价计算规则不受本次汇率统一影响。SEP 余额计算与同步尚未实现，后续可复用 `SettingService.GetPlatformExchangeRate`，不应再增加独立汇率。

`payment_orders.amount` 和 `refund_amount` 扩为 `decimal(20,8)`，支付网关金额保持原精度。部分退款按美元余额的实际比例计算，不再使用支付币种的一分钱容差把部分退款视为全额。
