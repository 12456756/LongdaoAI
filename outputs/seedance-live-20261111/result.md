## 已确认结果

1. `GET /v1/models` 返回 HTTP 200：当前 Key 可读取 `seedance-2.0`、`seedance-2.0-fast`、`seedance-2.0-mini`、`seedance-2.5`。

3. 所有报价来源均为 `group`，倍率为 1，币种 USD，计费方式为 `video`。这是 Longdao 对当前 Key 的账户扣费报价，不能据此确定脑生云上游的实际成本。
4. 使用 `seedance-2.0-mini`、4 秒、480p、16:9、关闭音频的请求体，附带故意不匹配的报价版本，检查当前平台能否在转发前执行报价保护。返回 HTTP 409、`X-Video-Dispatch: rejected`、`video_pricing_changed`。这是预期的主动拦截结果，不是自然发生的生成功能故障。
5. 对照本地 `backend/internal/handler/openai_videos.go`，该拦截位于鉴权、媒体权限、余额资格、账号选择之后，`ForwardVideo` 之前；据此可确认当前请求通过了前置检查并进入报价保护。本次没有创建视频任务，也没有生成任务 ID。

## 费用与验证边界

供应商文档的 Seedance 2.0 系列最短固定时长为 4 秒。当前平台对所有上述组合均报价 4 美元，降低模型档次或分辨率没有降低平台报价，不能按名称认定 Mini 更便宜。

用户要求低费用测试，因此在得知最低固定时长的报价后，暂未提交带有效报价版本的正式生成请求；需用户确认接受单次约 4 美元的平台额度扣费，或先校准分组定价后继续。未修改价格、模型映射、业务代码或生产部署。

本次不证明上游能受理、生成成功或可下载视频，也不证明上游不可用。480p 等具体规格是否受当前上游模型接受，仍待真实生成验证。
