## Caddy 实际生效配置

通过容器内只读访问 Caddy 管理 API，确认以下参数正在生效，非仅磁盘文件中的配置：

```caddyfile
reverse_proxy sub2api-blue:8080 sub2api-green:8080 {
    health_uri /health
    health_interval 3s
    health_timeout 2s
    health_status 200
    lb_policy first
    lb_try_duration 5s
    lb_try_interval 250ms
    fail_duration 10s
    max_fails 1
    unhealthy_status 500 502 503 504
}
```

Caddy 官方文档说明，`unhealthy_status` 将这些响应状态计为失败，`max_fails` 和 `fail_duration` 控制被动健康检查的失败阈值及记忆时间；当前配置会把业务接口 503 上升为整个应用实例不可用。

官方资料：https://caddyserver.com/docs/caddyfile/directives/reverse_proxy#passive-health-checks
