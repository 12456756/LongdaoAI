# 模型基础价格实施记录

日期：2026-11-20。范围：本工作树开发及隔离验证，尚未合并和部署。

## 已实现

- 账号新增上游公司归属，支持公司新建、编辑、删除和账号公司筛选。有关联账号的公司不能删除。
- 添加、编辑账号共用模型价格表单，保存上游模型、原价、采购折扣、公司加价倍数；普通创建及 Session/PAT 导入均透传到账号事务中保存。
- 新增 `/admin/model-pricing`，按公司分组、按账号分列比较候选价；支持搜索、公司、平台、计费方式、定价状态筛选、分页及账号列隐藏。
- 候选价格为 `上游原价 × 采购折扣 × 公司加价倍数`。管理员选择一个账号的完整价目，形成统一基础价快照及版本、修改历史。
- 来源价格修改后提示差异，由管理员手动更新。来源停用或移除后保留快照和来源名称，不绑定实际调用账号。
- 普通、流式、WebSocket、异步图片、视频、批量图片及报价接入新来源，保留现有用量归一化、倍率、冻结、结算规则。
- 可配置输入、输出、缓存读写、5 分钟/1 小时写入、图片 Token、图片按张、视频按秒及按次价格；保留 Priority/Flex、长上下文处理。
- 派发前校验模型和已知规格价格，保存请求价格快照。缺价不提交上游；正式收费不回退代码单价、旧 JSON 或渠道/分组单价。
- 分组页面旧图片/视频单价输入和默认价格预览已移除，倍率控件保留。用户侧可用渠道价格展示改读统一基础价。

## 数据与精度

新增迁移 `182_model_base_pricing.sql`、`183_model_base_price_decimal.sql`，包括公司、账号模型价格、基础价、历史、请求快照。账号保存与价目保存处于同一事务，并校验集合版本及单模型修订号。

价目存储为结构化 JSONB，原价使用十进制字符串；折扣和公司倍数有数据库 `NUMERIC(24,12)` 生成列。选定基础价时使用 PostgreSQL `NUMERIC` 重新计算金额，前端不决定最终价格。前端使用整数十进制乘法预览，后端独立精确校验。运行时适配现有计费结构和扣费精度。

本版直接读取数据库当前基础价，不设置跨请求价格缓存；请求内部使用固定快照，改价不影响在途请求。批量任务沿用提交时的单价及倍率快照，并关联基础价版本；拒绝用新基础价重算无快照的旧批量任务。

## 错误返回

| HTTP | 错误码 | 含义 |
|---|---|---|
| 400 | `invalid_model_price` | 模型、字段、精度或单位无效 |
| 400 | `invalid_upstream_company` | 公司输入无效 |
| 409 | `model_price_version_conflict` | 价格已变更，刷新后重新确认 |
| 409 | `model_price_source_unavailable` | 所选来源价目已失效 |
| 409 | `upstream_company_exists` | 公司名称重复 |
| 409 | `upstream_company_in_use` | 公司仍有关联账号 |
| 503 | `model_base_price_not_configured` | 模型未选择基础价 |
| 503 | `model_price_item_not_configured` | 规格或实际用量项目缺价 |
| 503 | `model_price_mode_mismatch` | 图片/视频接口与计费方式不匹配 |
| 503 | `model_pricing_service_unavailable` | 读取价格或保存快照失败 |

派发前拒绝时返回 `source=platform`、`dispatch=not_dispatched`、请求 ID，设置 `X-Model-Dispatch: rejected`。内部数据库错误不直接返回客户端。管理员页面保留后端文案，版本冲突后可刷新重新比较。

`0` 表示明确免费，未配置不会按免费结算。实际用量出现未配置的计费项时明确报错。

## 切换前

1. 管理员核实模型原价、折扣、公司加价并选择基础价。本次没有自动导入旧默认单价。
2. 执行新增迁移，盘点未定价模型、缺失规格、没有快照的在途任务。启用新代码后未定价模型拒绝请求。
3. 历史账单不重算，无快照旧批量任务单独处理。
4. 本次没有新增公开 Token 单价同步接口，没有修改业务平台代码。现有倍率和媒体报价契约继续使用。
5. `/v1/sub2api/usage` 原有确认逻辑针对图片/视频，文本请求可能返回 `transaction_confirmed_image_amount_unverified`。文本扣费本次核对实际余额和账务记录，不将此返回误认作未扣费。

旧价格数据仅用于能力发现、历史测试或一次性迁移参考，正式模型收费依赖数据库价格仓储。网页搜索是独立工具按次收费，沿用原有配置，不属于本次模型基础价替换。

### 白名单报价联动修正

- 报价编辑器移除“对外模型”“上游模型”输入框，模型名称仅在标题和模型列表中显示。模型来源由白名单或添加模型入口确定，上游映射在账号配置中维护；编辑价格保留既有模型与上游别名数据。

- 打开已有账号或新建账号时，根据完整白名单补齐多个报价草稿，覆盖白名单早于价格异步加载的情况。已填写价格和版本保持原值，通配符不生成具体模型报价。
- 新增白名单模型自动加入报价列表，展示白名单模型总数和填写数量；无映射时上游名默认同名，隐藏重复上游名称输入。补齐按钮可恢复手动移除的白名单报价。
- 报价列表可切换多个模型并保留各自输入，空白草稿仍不提交。59 项相关测试、类型检查和 ESLint 通过。浏览器脚本覆盖新增两个白名单模型、无需映射、切换保留报价；仅修改弹窗草稿，不提交账号修改。
